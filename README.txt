KONZOLOS RAJZOLO - .NET 8.0

A fájlokat a meglévő .NET 8.0 Console App projekt mappájába másold.
A régi Program.cs, Menu.cs, mintabetolto.cs, Nyomdak.cs és proba.cs fájlokat
előtte mentsd el, majd cseréld le az itt található azonos nevű fájlokra.
Az Allapot.cs és Felulet.cs új fájlok, ezeket is add hozzá a projekthez.
A minta.txt fájlt állítsd be: Properties > Copy to Output Directory > Copy if newer.

Vezérlés:
Nyilak: kurzor; Szóköz: toll fel/le; M vagy Tab: menü; Esc: kilépés.
F1-F3: X; F4-F6: kereszt; F7-F9: négyzetkeret; F10-F12: rombuszkeret.
Menü: karakter/szín váltása, minta betöltése, cellatörlés, középre ugrás, rajzlap törlése.
